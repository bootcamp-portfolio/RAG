# RAG Study

검색 증강 생성(Retrieval-Augmented Generation, RAG) 관련 수업 및 실습 자료를 정리하는 저장소입니다.

## 학습 목적
RAG 파이프라인의 구성 요소와 문서 처리, 검색 및 벡터 저장소 활용 과정을 복습합니다.

## 학습 방향
- 문서 수집 및 로딩
- 문서 분할과 노드 처리
- 임베딩 및 의미 유사도
- 벡터 인덱스와 검색
- 벡터 저장소 활용

## 참고
실습별 사용 라이브러리와 실행 방법은 코드 및 노트북을 확인해 주세요. 원본 작성자가 따로 있는 자료를 가져온 경우 원본 저장소와 작성자를 명시해 주세요.
